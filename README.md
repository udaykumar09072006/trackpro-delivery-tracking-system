# 📦 TrackPro – Delivery Tracking System

A responsive delivery tracking and management web application designed to help users monitor package status, manage deliveries, and organize courier operations through a centralized dashboard.

🔗 **Live Demo:** https://trackpro-delivery-system-4jbnmgtqr.vercel.app

## ✨ Features

- **Dashboard:** View package summaries, delivery statistics, and recent updates.
- **Package Tracking:** Search packages using a tracking ID and view their delivery progress.
- **Package Management:** Add, edit, delete, and manage package details.
- **Delivery Timeline:** Follow delivery progress through status updates.
- **Courier Management:** Organize courier details and delivery assignments.
- **Route Management:** View and manage delivery route information.
- **Notifications:** Demonstrate delivery status notifications using simulated data.
- **Reports & Analytics:** Present delivery statistics and performance summaries.
- **Login & Registration UI:** Provide authentication screens for the application.
- **Responsive Design:** Support desktop, tablet, and mobile layouts.

## 📦 Delivery Statuses

- 🟡 Pending
- 🔄 In Transit
- 📍 Out for Delivery
- ✅ Delivered
- ❌ Failed

## 🛠️ Tech Stack

- **HTML5** – Web page structure
- **CSS3** – Styling and responsive layouts
- **JavaScript** – Interactivity and application logic
- **Vercel** – Deployment
- **Git & GitHub** – Version control

## 🎯 Project Objective

The objective of TrackPro is to provide a simple interface for tracking packages and managing delivery operations. It brings package information, delivery timelines, courier details, and analytics together in one organized application.
